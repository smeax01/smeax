# Smeax - Portfolio 🚀

Bienvenue sur le dépôt de mon portfolio personnel. Un site web moderne, performant et responsive construit avec **Astro** et **Tailwind CSS**.

## 🌐 Live Demo

Découvrez le site en ligne : [https://smeax01.github.io/smeax/](https://smeax01.github.io/smeax/)

## 🛠️ Technologies utilisées

- **Framework** : [Astro](https://astro.build/)
- **Styling** : [Tailwind CSS v4](https://tailwindcss.com/)
- **Icônes** : [Lucide Icons](https://lucide.dev/)
- **Animations** : CSS natif & Tailwind
- **Langues** : Système de traduction i18n (FR/EN)

## 📁 Structure du Projet

```text
/
├── public/          # Assets statiques (images, icons)
├── src/
│   ├── components/  # Composants Astro réutilisables
│   ├── layouts/     # Layouts de base
│   ├── pages/       # Pages du site (index, projects, contact, etc.)
│   ├── data/        # Données des projets et compétences
│   └── i18n/        # Système de traduction
├── dist/            # Dossier de build (généré)
└── astro.config.mjs # Configuration Astro
```

## 🚀 Installation locale

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/smeax01/smeax.git
   ```
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

## 📦 Build et Déploiement

Pour générer la version statique du site :

```bash
npm run build
```

Les fichiers sont générés dans le dossier `dist/`.
